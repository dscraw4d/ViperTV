# Contributing to ViperTV

Thanks for helping improve ViperTV.

1. Open an Issue for bugs or proposed features when practical.
2. Fork the repository and create a feature branch for code changes.
3. Keep private data out of commits: never commit `.env`, databases, Plex tokens, API keys, media files, or backup data.
4. Test the Docker build and the areas of ViperTV affected by your change.
5. Open a Pull Request describing what changed and how it was tested.
